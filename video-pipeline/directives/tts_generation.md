# Directive: TTS Audio Generation

## Goal

Convert video scripts into high-quality voiceover audio files using text-to-speech. Clean all non-spoken content from scripts before synthesis. Handle chunking for long scripts, voice profile selection per channel, and fallback TTS engines when ElevenLabs quota is exhausted.

## Inputs

- **script files**: `.txt` files in `output/scripts/` (generated by `batch_generate_scripts.py` or `faceless_pipeline.py`)
- **channels_config.json**: Contains `voice_profiles` mapping with voice IDs and settings per channel
- **ELEVENLABS_API_KEY**: API key from `../shopify-theme/.env`

## Execution Scripts

| Script | Purpose |
|--------|---------|
| `batch_generate_audio.py` | Batch TTS for all scripts missing audio |
| `faceless_pipeline.py audio <channel> <topic>` | Single-script TTS via the faceless pipeline |
| `produce_video.py audio <topic>` | Single-script TTS for avatar channel (CumquatVibes) |

## Steps

### 1. Find Scripts Needing Audio

`batch_generate_audio.py` scans `output/scripts/` for `.txt` files and checks if a matching `.mp3` exists in `output/audio/`. The audio filename is derived from the script filename by stripping the timestamp suffix (e.g., `RichTech_Best_AI_Tools_20260221_193640.txt` -> `RichTech_Best_AI_Tools.mp3`).

### 2. Determine Voice Profile

Each channel has a `voice_profile` in `channels_config.json` that maps to a voice preset:
- The profile specifies an ElevenLabs `voice_id`, `stability`, `similarity_boost`, `style`, and `model`
- Default model: `eleven_multilingual_v2`
- Default voice ID: `cjVigY5qzO86Huf0OWal` (fallback neutral male)
- Channel -> profile lookup: `channels[ch_key]["voice_profile"]` -> `voice_profiles[profile_name]`

### 3. Clean Script for TTS

The `clean_script_for_tts()` function strips all non-spoken content. This is critical -- if anything leaks through, the voice will read metadata, stage directions, or formatting aloud.

**Cleaning rules (in order):**

1. **YAML frontmatter**: Removes `` ```yaml ... ``` `` and `--- ... ---` blocks
2. **VIDEO_METADATA block**: Removes `VIDEO_METADATA:` followed by indented key-value lines
3. **Metadata header lines**: Removes `# Channel:`, `# Topic:`, `# Voice:`, `# Speed:`, etc.
4. **"Here's the complete script" intro**: Removes Gemini's preamble lines
5. **Bracketed stage directions**: Removes `[VISUAL:...]`, `[HOOK]`, `[INTRO - HOOK]`, `[CHAPTER:...]`, `[PAUSE]`, `[RETENTION HOOK:...]`, `[SECTION:...]`, `[CTA]`, `[OUTRO]`, `[TRANSITION]`
6. **Emotion tags preserved**: ElevenLabs recognizes `[excited]`, `[calm]`, `[confident]`, `[whispers]`, `[laughs]`, etc. -- these are kept. A whitelist of ~35 emotion tags is checked.
7. **Section header patterns**: Removes `00:00 - HOOK:`, `HOOK & RETENTION (...):`, etc.
8. **Markdown headers**: Removes `##` and `#` prefixes but keeps spoken text after labels (e.g., `## 00:00 - HOOK: The AI Revolution` -> `The AI Revolution`)
9. **Timestamp prefixes**: Strips `00:30 - ` from lines (structural markers)
10. **Markdown bold/italic**: Removes `**` and `*` wrapping
11. **Parenthetical timestamps**: Removes `(0:00-0:30)` patterns
12. **Word count markers**: Removes `(Word count so far: 312)` patterns
13. **Citation markers**: Removes `[3]`, `[5]`, `[inspired by 3]`
14. **Whitespace cleanup**: Collapses 3+ newlines to 2

### 4. Chunk Long Scripts

ElevenLabs has a ~5000 character limit per API request. For scripts exceeding 4500 chars:
- Split on paragraph boundaries (`\n\n`)
- Build chunks up to 4500 chars each
- Each chunk is sent as a separate API call
- Audio bytes are concatenated in order
- 1-second sleep between chunks for rate limiting

### 5. Generate Audio

API call to `https://api.elevenlabs.io/v1/text-to-speech/{voice_id}`:
- Request body: `text`, `model_id`, `voice_settings` (stability, similarity_boost, style, use_speaker_boost)
- Response: raw MP3 audio bytes
- Timeout: 120 seconds per chunk
- Audio saved to `output/audio/{script_name}.mp3`
- 1-second sleep between scripts for rate limiting

### 6. Skip Short Scripts

Scripts with cleaned text under 100 characters are skipped (likely malformed or empty after cleaning).

## TTS Engine Comparison

| Engine | Quality | Cost | Speed | Best For |
|--------|---------|------|-------|----------|
| **ElevenLabs** | Excellent (emotion tags, natural prosody) | ~$22/mo for 100K chars | Slow (network) | Priority channels, high-quality voiceover |
| **edge-tts** | Good (Microsoft Azure voices) | Free | Fast | Bulk generation, non-priority channels |
| **F5-TTS** | Good (local, customizable) | Free (compute only) | Medium | Offline generation, PC-side processing |

### ElevenLabs Quota Management

- Starter plan: 30,000 characters/month
- Scale plan: 100,000 characters/month
- Average script: 4,000-8,000 characters
- At 100K chars: ~12-25 videos per month
- Monitor usage at https://elevenlabs.io/subscription

### Fallback Strategy

When ElevenLabs quota is exhausted:
1. Check if the channel is priority tier -- if so, wait for quota reset or upgrade plan
2. For non-priority channels, use edge-tts: `edge-tts --voice en-US-GuyNeural --text "..." --write-media output.mp3`
3. For PC-side processing, use F5-TTS with a cloned voice model
4. Richard prefers to record voiceovers himself for CumquatVibes -- do not use TTS for that channel unless explicitly asked

## Edge Cases / Known Issues

1. **`[^:]` regex eating body text**: The original header-stripping regex used `[^:]` which matched across newlines, consuming entire paragraphs after a colon. Fixed by using `[^:\n]*` to prevent cross-line matching. If audio sounds like it's missing sections, check `clean_script_for_tts()` regexes.

2. **VIDEO_METADATA not stripped**: Gemini sometimes generates a `VIDEO_METADATA:` block at the top of scripts. If not cleaned, the voice reads "title colon Best AI Tools..." aloud. The dedicated regex `r'^VIDEO_METADATA:\s*\n(?:\s+\w.*\n)*'` handles this.

3. **ElevenLabs 429 rate limits**: The API returns 429 when sending requests too fast. The batch script has a 1-second delay between scripts. If you still hit 429s, increase the delay or reduce batch size.

4. **Chunking at paragraph boundaries may split sentences**: If a script has very long paragraphs (no `\n\n` breaks), a single paragraph exceeding 4500 chars will be sent as-is, which may fail. Pre-process such scripts to add paragraph breaks.

5. **Emotion tags must be lowercase**: ElevenLabs only recognizes lowercase emotion tags like `[excited]`. If Gemini generates `[EXCITED]`, the cleaning function won't match it as an emotion tag and will strip it. The whitelist check uses `.lower()` so this should work, but verify if new tags are added.

6. **Audio concatenation produces audible seams**: When scripts are chunked, the concatenated MP3 may have slight pauses or tonal shifts at chunk boundaries. For critical videos, consider sending the entire script as one request (may require upgrading the ElevenLabs plan for higher character limits per request).

## Learnings

- The `eleven_multilingual_v2` model produces the most natural-sounding English voiceover, even for English-only content.
- `use_speaker_boost: true` significantly improves clarity for faceless YouTube content.
- Stability 0.5 and similarity_boost 0.75 are good defaults. Lower stability = more expressive but less consistent between chunks.
- Style parameter 0.2 adds subtle personality without being distracting.
- Scripts averaging 1200 words produce ~8 minute videos, which is the sweet spot for YouTube ad revenue eligibility (8+ minutes allows mid-roll ads).
